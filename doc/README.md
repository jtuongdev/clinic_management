# Tai lieu ClinicManagement

Tai lieu duoc sap xep theo **hanh vi nghiep vu** va **muc dich su dung**, khong dat lan tron tai lieu tong quan, flow, API va bao cao nghiem thu.

## Cay thu muc

```text
doc/
├── 00-tong-quan/          # Kien truc, hien trang, domain va database
├── 01-flow-nghiep-vu/     # Flow tiep don, kham benh, EMR, dieu tri
├── 02-gap-analysis/       # Gap analysis, checklist va danh gia tien do
├── 03-backend-api/        # API contract, governance, business rules, test HTTP
├── 04-admin-ui/           # Contract va handoff cho AdminUI
├── 05-ke-hoach-ky-thuat/  # Ke hoach DTO, phan ky va quy uoc code
├── 06-kho-duoc/           # Kho, duoc, vat tu va ton kho
├── 07-vien-phi/           # Billing, hoa don, phieu thu va thu tien
├── 08-ux-lich-lam-viec/   # UX va ke hoach lich lam viec
└── 09-nghiem-thu/         # Doi chieu, xac minh va bien ban nghiem thu
```
